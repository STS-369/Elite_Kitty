# Kitty Soldier: Rambo Cat vs. The Rats

A high-octane, side-scrolling platformer built with **Phaser.js**. Take control of Kitty Soldier, a tactical feline on a mission to clear the world of a procedural rat infestation.

## 🎮 Gameplay Features
- **Procedural Difficulty:** Enemies get faster and more numerous every time you loop through the 3 base levels.
- **Tactical Combat:** Fire yarn balls to eliminate rats before they reach you.
- **Infinite Looping:** Survive through the Alley, Sewer, and Warehouse as the challenge scales infinitely.
- **Rambo Aesthetic:** Gritty urban environments and a determined kitty protagonist.

## ⌨️ Controls
- **WASD / Arrow Keys:** Move and Jump
- **Space / Z:** Shoot Projectiles

## 🛠️ Tech Stack
- **Engine:** Phaser.js (Arcade Physics)
- **Logic:** Vanilla JavaScript (ES6+)
- **Styling:** CSS3 (Cyberpunk/Tactical theme)
- **Deployment:** GitHub Pages compatible

## 🚀 Setup & Installation
1. Clone the repository: `git clone https://github.com/STS-369/Elite_Kitty.git`
2. Open `index.html` in any modern web browser.
3. (Optional) Host via GitHub Pages: Go to Settings > Pages > Select `main` branch.
